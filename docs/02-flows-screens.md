# 2. 사용자 흐름 3개 · 화면 목록

## 2-1. 사용자 흐름

### 흐름 A — 신규: 가입 없이 첫 판 → 구단 선택 → 공유 (D0 핵심)
```
앱 실행 ─(첫 실행)→ [퀴즈]  ← 홈을 거치지 않고 바로 시작 (랜딩/가입/튜토리얼 없음)
  [3D] 주심 시점: 마운드에서 공 비행(1.0초, 실제 0.4~0.6초의 약 2배 슬로모) → 공이 플레이트 앞면에서 멈춤 → 스트라이크/볼 탭(최대 4초)
  → 즉시 ABS 공개: 3D 존 박스 페이드인 220ms + 카메라가 1루 쪽 리플레이 시점으로 이동 → 판정 색 궤적/통과 링 → 판정 도장 250ms + 햅틱
  → 5구 반복 (한 판 ≈ 25~32초)
        ↓
     [결과]  정확도 카운트업 → ★공유하기 버튼(가장 큰 요소, 300ms 팝)
        ├─ 응원 구단 미선택 → "구단 고르면 이번 판이 대항전에 반영" → [구단 선택] → 앱 컬러가 구단색으로 변경
        ├─ 알림 동의 카드(첫 판 직후, 맥락 있는 요청)
        └─ [공유 카드] 스토리 9:16 / 카톡 1:1 → 시스템 공유 시트
```
이탈 방어: 가입·권한·구단 선택을 **첫 판 이후**로 미룸. 알림 권한 요청도 첫 판 결과에서만.

### 흐름 B — 복귀: 푸시 → 오늘의 논란 판정 → 공유 (D1/D7 핵심)
```
매일 17:30 푸시(날짜별 문구) ─ 또는 ─ 21:30 "N일 연속 기록이 곧 끊겨요"(스트릭 2일↑ & 오늘 미플레이)
  → [오늘의 퀴즈 탭] 오늘의 논란 판정 3개 (모두 같은 투구, 자정 KST 갱신)
  → [논란 판정] 투구 도착 → 스트라이크/볼 투표(1탭)
  → 공개: "팬 투표 vs ABS" · 전체 팬 / 내 구단 팬 비율 · 내가 ABS와 일치했는지
  → [공유하기] 논란 판정 카드(이미지) — 커뮤니티 업로드용 / (서버) 5초 클립 mp4 자동 생성
  → [다음 논란] → [구단 랭킹] 내 기여도 갱신 확인
```

### 흐름 C — 확산: 미니 리그 생성 → 링크 → 친구 가입 없이 참여
```
[오늘/랭킹/내 기록] "리그 만들기" → 이름 + (친구|구단 팬) → 6자 코드 발급
  → [리그 상세] "초대 링크 보내기" → 시스템 공유 시트(카톡 등) https://bravekoon.github.io/-/l/?c=K7M2QX (웹 착지 → strzone://l/K7M2QX)
        ↓ 친구
  링크 탭 → (앱 설치됨) 딥링크로 [리그 착지] / (미설치) 스토어 → 설치 후 디퍼드 딥링크(Phase 1)
  → "이 리그에 참여할까요?" 1탭 참여 (가입 불필요) → 바로 [퀴즈] 첫 판
  → 이번 주 리그 순위(정확도)에 반영
```

## 2-3. 스타일/접근성 구현 요약

- **전광판 다크**: 배경 `#0B0F14`, LED 도트 패턴(공유 카드), 숫자는 `fontVariant: tabular-nums` + 900 굵기 큰 타이포(정확도 112pt).
- **구단 컬러 자동 적용**: 선택 즉시 `accent`가 구단색으로 변경. 어두운 구단색(두산·롯데·키움 등)은 `ensureContrastOnDark()`가 **배경 대비 4.5:1**이 될 때까지 밝혀 자동 보정(테스트로 10개 구단 × 3개 배경 전수 검증).
- **3D 스테이지**: 밤 구장(잔디·흙·마운드·홈플레이트·타석·파울라인), 외야 **구단 컬러 리본 전광판**, 타자(신장 반영), 실밥 있는 공. 카메라 이동(약 0.5초)은 화면 전환 연출로 150~300ms 규칙의 예외. 모션 줄이기면 비행·카메라 이동 없이 즉시 표시. 설정 "3D 판정 연출"로 끌 수 있음.
- **마이크로 모션 150~300ms**: 버튼 프레스 150ms, 존 페이드인 220ms, 도장 250ms, 공유 버튼 팝 150+150ms, 숫자 카운트업 600ms(결과 강조용 예외). **모션 줄이기** 설정이면 전부 0ms.
- **햅틱**: 탭=selection, 정답=Success, 오답=Warning, 라운드 완료=Heavy. 설정에서 끌 수 있음.
- **접근성(AA 지향)**: 텍스트 대비 4.5:1 이상(테스트), 터치 타깃 ≥ 56dp, 정답/오답은 색 + 기호(✓/✕) + 텍스트 병기, 스테이지에 스크린리더 라벨(정답을 노출하지 않는 위치 수치 설명), 시간 제한 해제 옵션(WCAG 2.2.1), 폰트 확대 허용(상한 1.6배, 큰 숫자 1.2~1.3배).
- ⚠️ 위 접근성은 **자동 검증 가능한 항목(대비·타깃 크기)만 검증**했고, VoiceOver/TalkBack 실기기 점검과 외부 감사는 Phase 1 과제입니다.
