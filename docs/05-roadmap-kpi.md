## 5-3. 성공/실패 기준 (수치)

| 지표 | 알파 게이트 (2/7, N≥150) | 베타 게이트 (2/28, N≥1,500) | **개막 후 4주 성공** | 경고 | **실패(행동 트리거)** |
|---|---|---|---|---|---|
| 첫 판 완주율 | ≥ 85% | ≥ 88% | ≥ 90% | 70~85% | **< 70%** → 퀴즈 UX 재설계 우선 |
| D1 재방문 | ≥ 30% | ≥ 35% | **≥ 35%** | 20~35% | **< 20%** |
| D7 재방문 | ≥ 10% | ≥ 15% | **≥ 15%** | 8~15% | **< 8%** |
| 공유율 | ≥ 8% | ≥ 12% | **≥ 12%** | 5~12% | **< 5%** |
| 공유 완료율 | ≥ 60% | ≥ 70% | ≥ 70% | 40~70% | < 40% → 카드/공유 시트 UX 점검 |
| 친구 초대율(/WAU) | ≥ 4% | ≥ 8% | **≥ 8%** | 3~8% | **< 3%** |
| K-factor | — | ≥ 0.15 | ≥ 0.25 | 0.05~0.25 | < 0.05 |
| 구단 선택률 | ≥ 60% | ≥ 70% | ≥ 70% | 50~70% | < 50% → 선택 유도 위치 변경 |
| 푸시 동의율 | ≥ 40% | ≥ 50% | ≥ 50% | 30~50% | < 30% → 요청 시점/문구 변경 |
| 논란 판정 참여율(DAU 중) | ≥ 30% | ≥ 40% | ≥ 40% | 20~40% | < 20% → 노출 위치/알림 문구 변경 |
| 크래시 프리 세션 | ≥ 99% | ≥ 99.5% | ≥ 99.5% | 98.5~99.5% | < 98.5% → 출시 보류 |
| 누적 설치(가정 A11) | 150 | 1,500 | 10,000 | — | 베타 < 500이면 모집 채널 재검토 |

### 의사결정 규칙
1. **알파 게이트 미달(2/7)**: 미달 지표 1개 → 1주 연장 + 해당 실험 집중. **D1 < 20% 또는 첫 판 완주율 < 70%** → 코어 루프 문제로 보고 대항전/리그 개발을 멈추고 퀴즈 경험부터 수정.
2. **베타 게이트(2/28)**: 성공 지표 4개 이상 달성 → 3/20 출시 유지. D1/D7 경고 구간 → 출시는 하되 "논란 판정 데일리 + 클립" 중심으로 개막 캠페인 축소. **D1 < 20% & D7 < 8%가 2회 개선 사이클 후에도 지속** → 솔로 퀴즈형 제품 가설 폐기, **콘텐츠형(논란 판정 클립 + 팬 투표 + 카드 공유)으로 피벗**, 앱은 개막에 맞춰 최소 기능으로 출시.
3. **출시 게이트(3/19)**: ① 크래시 프리 ≥ 99.5% ② 법무 3건 승인(구단명/색/로고 범위, 14세 미만 처리, 시뮬레이션 고지·베팅 아님 문구) ③ 스토어 승인 ④ 서버 부하 5배 여유 — **하나라도 미달이면 출시일을 미루지 말고 해당 기능을 끄고** 출시(예: 리그 기능 숨김).
4. **개막 후 4주(4/24)**: 성공 지표(굵은 글씨) 중 **공유율·D1·D7 3개 모두 성공 → 판정 모드 확장/실데이터 투자**, 1~2개 → 현 구조 유지하며 개선, **0개 → 다음 시즌 전까지 유지보수 모드**.

## 5-4. 알파 중 실험(최대 4건 동시)
1. 푸시 시각: 고정 17:30 vs 경기 시작 90분 전 (스트릭 보호 푸시 21:30 유지)
2. 결과 화면 CTA: 공유 버튼 문구/위치, 구단 선택 유도 카드 위/아래
3. 구단 선택 시점: 첫 판 결과 후(현재) vs 첫 판 시작 전
4. 공유 카드 기본 포맷: 스토리 9:16 vs 카톡 1:1
