# 1. 차별화 포인트 — 스트존 vs 기존 판정 게임

> **비교 기준에 대한 정직한 고지**: "기존 판정 게임"은 사용자가 준 전제(인간 ABS: 판정 4모드, 3D 연출, 솔로 플레이)와 일반적인 *솔로형 판정 퀴즈*의 공통 구조를 기준으로 했습니다. 시장의 다른 앱을 개별 조사한 결과가 아니며, 경쟁앱 실사(스토어 리뷰·리텐션 추정)는 로드맵 Phase 0 과제입니다.

## 1-1. 한눈에 비교

| 축 | 기존 판정 게임 (인간 ABS 등 솔로형) | **스트존** | 왜 이게 정면충돌을 피하는가 |
|---|---|---|---|
| 핵심 재미 | "내 눈이 ABS와 같나" — **개인 숙련** | "**우리 구단 팬**이 더 정확한가" — **집단 정체성** | 같은 판정 동작을 쓰지만 보상 구조가 개인→집단으로 이동 |
| 경쟁 단위 | 나 vs 기록 / 글로벌 점수 | **구단 vs 구단**(주간 시즌), 친구/구단 미니 리그 | 야구 팬 고유의 소속감(응원 구단)을 게임 루프에 넣음 |
| 콘텐츠 | 무한 반복 문제(생성형) | **오늘의 논란 판정** — 하루 1~3개 *모두가 같은 투구*를 보고 **팬 투표 vs ABS** 공개 | 같은 문제를 같은 날 푼다 → 대화·논쟁 소재가 생김 |
| 판정 모드 | 4모드 + 3D 연출 | **볼/스트라이크 1개에 집중**, 3D 판정 스테이지(주심 시점 → 리플레이 시점 존 공개) | 3D는 *연출 수단*일 뿐 경쟁 축이 아님. 모드 수·연출 화려함으로 경쟁하지 않음 |
| 공유 자산 | 점수 스크린샷 수준 | **공유 카드**(정확도·스트릭·구단 기여도) + **논란 판정 카드/클립 자동 생성** | 커뮤니티/유튜브에 *올릴 이유가 있는* 콘텐츠 |
| 리텐션 루프 | 개인 스트릭/신기록 | 주간 시즌 리셋(월 00:00 KST) + 스트릭 + 매일 17:30 푸시 + 끊김 직전 푸시 | "이번 주 순위" 때문에 월요일에도 돌아올 이유 |
| 바이럴 루프 | 약함(솔로) | 초대 링크 하나로 리그 생성 → **가입 없이 참여** | 친구 1명 초대 = 순위표가 생김 |
| 온보딩 | 일반적으로 설정/튜토리얼 | **가입 없이 첫 판 즉시 시작**, 결과 화면에서 구단 선택 | 첫 판 완주 전 이탈 지점 제거 |
| 데이터 | 시뮬레이션/자체 생성 | 시뮬레이션 기본 + **라이선스 확보 시 실제 투구**로 교체 가능한 `PitchSource` 경계 | 데이터 확보 불확실성이 출시 일정을 막지 않음 |
| 수익/규제 | 광고/IAP | **금전 보상·베팅 없음**(배지·칭호만) | 승부예측/도박 연상 리스크 차단 |

## 1-2. 공존 전략 (가정 A8: 두 앱의 운영 주체가 같다)

- 판정 엔진(`src/core/zone.ts`, 투구 생성기)은 **공통 라이브러리**로 공유 가능 → 인간 ABS의 3D 연출/모드는 그대로 두고, 스트존은 *소셜 레이어*만 책임진다.
- 교차 유입: 인간 ABS 결과 화면에 "우리 구단 대항전" 딥링크(`strzone://`) / 스트존 결과 화면에 "더 많은 모드는 인간 ABS". 사용자 풀이 겹치는 만큼 **상호 유입 실험**(A/B)으로 카니발라이제이션을 측정한다.
- 운영 주체가 다르면 위 항목은 *포지셔닝 문서*로만 사용하고 코드 공유는 하지 않는다.

## 1-3. 슬로건을 지키기 위한 주의

"우리 구단 팬이 심판보다 정확하다"는 **브랜딩 카피**입니다. 앱 안에서는 *실제 심판(주심)이나 특정 구단 팬을 비하/단정*하지 않도록, 비교 대상을 "ABS 판정"과 "리그 평균 정확도"로 한정했습니다. 사실 주장으로 쓰려면 근거 데이터가 필요합니다.

## 1-4. 3D 연출 도입에 대한 메모 (2026-11-25 추가)
요청에 따라 판정 스테이지를 3D로 바꿨습니다. 인간 ABS도 3D 연출을 갖고 있으므로 **"보기에 비슷한 앱"**이 될 위험이 있습니다. 그래서 3D는 다음 원칙으로 제한했습니다.
- 3D는 *판정 정보를 더 정확히 보여주는 용도*(주심 시점 원근, 존의 앞면/깊이, 궤적)로만 쓰고, 모드·카메라 수·이펙트 경쟁은 하지 않는다.
- 차별화의 핵심(구단 대항전·논란 판정·공유·리그)은 그대로다. 마케팅 메시지에서 3D를 앞세우지 않는다.
- 설정에서 끌 수 있고(2D 간단 보기), 저사양/WebGL 미지원 기기는 자동으로 2D.
