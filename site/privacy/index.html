개인정보처리방침

시행일: 2026년 11월 26일 · 적용 버전: 스트존 0.x

1. 요약

스트존은 회원가입 없이 사용하는 앱이며, 현재 버전은 어떤 개인정보도 운영자의 서버로 전송·수집하지 않습니다. 앱에서 만들어지는 정보는 모두 사용자의 기기 안에만 저장됩니다.

2. 기기에 저장되는 정보

항목목적보관
임의 생성 식별자(익명 ID), 자동 생성 닉네임기록 구분앱 삭제 시 함께 삭제
응원 구단구단 대항전 표시, 앱 색상
판정 기록(정답 여부·점수·연속 기록), 논란 판정 투표내 기록·순위·공유 카드
설정(알림·진동·3D 연출·시간 제한)사용 환경 유지

위 정보는 운영자에게 전송되지 않으며, 제3자에게 제공·판매하지 않습니다. 광고 식별자(IDFA)를 사용하지 않고, 사용자를 추적하지 않습니다.

3. 알림

알림을 허용하면 하루 최대 2회(매일 같은 시간 1회, 연속 기록이 끊기기 직전 1회) 기기 안에서 예약된 로컬 알림만 보냅니다. 푸시 토큰을 수집하지 않습니다. 알림은 앱의 [내 기록 → 설정] 또는 기기 설정에서 끌 수 있습니다.

4. 공유

공유 카드 이미지는 기기에서 만들어지며, 사용자가 직접 선택한 앱(카카오톡, 인스타그램 등)으로만 전달됩니다. 공유된 이후의 처리는 해당 서비스의 정책을 따릅니다.

5. 만 14세 미만 아동

현재 버전은 개인정보를 수집하지 않으므로 별도의 법정대리인 동의 절차가 없습니다. 이후 계정·서버 기능을 도입할 경우 관련 법령에 따른 동의 절차를 마련하고 이 방침을 개정합니다.

6. 정보 삭제

앱을 삭제하면 기기에 저장된 모든 정보가 삭제됩니다.

7. 방침 변경

서버 연동(구단 순위·팬 투표·리그의 실시간 집계) 등으로 처리 항목이 바뀌면, 시행 전에 이 페이지와 앱 안에서 알립니다.

8. 문의

고객지원 페이지를 이용해 주세요.
